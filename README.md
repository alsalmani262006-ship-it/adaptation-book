# التكيّف لدى الكائنات الحية: كتاب إلكتروني تفاعلي

كتاب عربي في مادة العلوم من 20 صفحة. الصفحات 1–5 للمحتوى العلمي، والصفحات 6–20 لـ 15 نشاطًا تفاعليًا، ولكل نشاط لعبة مستقلة لها رابط خاص.
المحتوى العلمي مأخوذ من الدرس ٧-١ «التكيُّف» فقط، ومحفوظ في [`content/extracted_content.md`](content/extracted_content.md).

## التشغيل محليًا

المتطلبات: Node.js 18 أو أحدث، ومتصفح Edge أو Chrome (يُستخدمان للاختبار وتصدير PDF فقط).

```bash
npm install        # مرة واحدة فقط
npm start          # ثم افتح http://localhost:8080/
```

- الكتاب: `http://localhost:8080/book/index.html`
- أي لعبة مباشرة: `http://localhost:8080/games/game-01/` حتى `game-15/`

> يمكن أيضًا فتح `book/index.html` بالنقر المزدوج دون خادم، لكن الخادم المحلي يمثّل بيئة النشر بدقة أكبر.

### التنقّل في الكتاب
- زرّا ← و→ على جانبي الكتاب، أو مفاتيح الأسهم في لوحة المفاتيح. في الكتاب العربي، السهم ← يعني «التالي».
- على الهاتف: اسحب الصفحة إلى اليمين لتنتقل إلى الصفحة التالية.
- ☰ للفهرس، 🔍 للتكبير، 🖨 للطباعة أو الحفظ PDF.
- على الشاشات العريضة تظهر صفحتان متقابلتان، وعلى الهاتف صفحة واحدة، مع حركة تقليب ثلاثية الأبعاد.

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `npm start` | خادم محلي على المنفذ 8080 |
| `npm test` | اختبار آلي في متصفح حقيقي: الصفحات العشرون، والتنقّل، والألعاب الخمس عشرة (إجابة صحيحة، وإجابة خاطئة، وحلّ كامل، وعرض الهاتف) |
| `npm run pdf` | تصدير الكتاب إلى `dist/pdf/adaptation-book.pdf` (20 صفحة A4)، مع التحقق من عدد الصفحات |
| `npm run previews` | إعادة التقاط صور المعاينة في صفحات الأنشطة من الألعاب نفسها |
| `npm run qr -- <الرابط>` | توليد رموز QR بعد النشر (انظر أدناه) |

## بيانات الغلاف
اسم المعدّ والرقم الجامعي والصف الدراسي حقول فارغة. يمكن ملؤها بإحدى طريقتين:
1. **بشكل دائم:** اكتب القيم في [`book/config.js`](book/config.js)، فتظهر في نسخة الويب وفي ملف PDF.
2. **مؤقتًا:** اكتب على الغلاف مباشرة في المتصفح، وتُحفظ على ذلك الجهاز فقط.

## النشر على GitHub Pages (بعد موافقتك فقط)

المسارات كلها نسبية، فيعمل المشروع من أي مسار فرعي مثل `https://<user>.github.io/<repo>/`.

1. أنشئ مستودعًا جديدًا على GitHub، مثلًا `adaptation-book`.
2. ارفع المشروع. ملف `.gitignore` يستبعد `node_modules/` و`dist/` و`references/` (صور الكتاب المدرسي ذات العلامة المائية):
   ```bash
   git init && git add . && git commit -m "الكتاب التفاعلي: التكيّف لدى الكائنات الحية"
   git branch -M main
   git remote add origin https://github.com/<user>/adaptation-book.git
   git push -u origin main
   ```
3. في إعدادات المستودع: **Settings ← Pages ← Source: Deploy from a branch ← main / (root)**.
4. بعد دقائق يعمل الكتاب على `https://<user>.github.io/adaptation-book/` (الصفحة الجذرية تحوّل إلى الكتاب تلقائيًا).
5. **رموز QR:** ولّدها من الرابط الحقيقي، ثم ارفعها وأعد تصدير PDF:
   ```bash
   npm run qr -- https://<user>.github.io/adaptation-book/
   npm run pdf
   git add qr && git commit -m "رموز QR" && git push
   ```
   قبل هذه الخطوة تظهر في صفحات الأنشطة مساحة مخصّصة لرمز QR دون أي رابط.

روابط الألعاب المستقلة بعد النشر تكون بالشكل: `https://<user>.github.io/adaptation-book/games/game-01/` … `game-15/`.

## بنية المشروع

```
index.html            تحويل إلى الكتاب (للاستضافة)
book/                 الكتاب: index.html، config.js، js/pages.js (الصفحات)، js/viewer.js (العارض والتقليب)، css/book.css
games/game-01…15/     الألعاب: كل لعبة index.html + game.js + style.css، وتعمل مستقلة
shared/js/data.js     المصدر الوحيد للمحتوى العلمي، وتقرأ منه الألعاب والكتاب
shared/js/art.js      رسوم SVG أصلية (السمكة، الحصيني، الصبّار، العُقاب، المواطن…)
shared/js/kit.js      محرّك الألعاب: النقاط، والتصحيح الفوري، والأصوات، والاحتفال، والسحب والإفلات
shared/js/games.js    سجلّ الأنشطة (العنوان، الهدف، التعليمات)، ويُستخدم في الكتاب والألعاب
shared/fonts/         خط Cairo محليًا (يعمل دون إنترنت)
qr/                   رموز QR وملف qr-data.js
scripts/              الخادم، والاختبار، وتصدير PDF، والمعاينات، وQR
content/              المحتوى المستخرج من صور الدرس
references/           صور الدرس الأصلية (للمرجع فقط، لا تُنشر)
```
